## Context

**GDD**: `design/gdd/content-data-definitions.md` (CD8; CD10 for the M-1a enum fields)
**Requirement**: `TR-content-012`
*(Requirement text: `docs/architecture/tr-registry.yaml`.)*

**ADR Governing Implementation**: ADR-0010: Content Format, Loading, ContentSet and StatSheet (§2 Enums)
**ADR Decision Summary**: Content enums are closed C# enums with explicit numeric values that are never reused. Each has a snake_case ↔ member table generated at compile time; a source generator is allowed. Runtime reflection and `Enum.Parse` are not allowed.
**ADR Version**: 2026-10-16

**Engine**: Godot 4.7.1 (Godot-free Sim code) | **Risk**: LOW
**Engine Notes**: Compile-time tables are trim-safe. This matters for the deferred S2 export spike, but nothing here depends on it.

**Control Manifest Rules (Foundation)**:
- Required: enums are closed C# enums with explicit never-reused values. snake_case ↔ member tables are generated at compile time (a source generator is allowed). (ADR-0010 §2)
- Forbidden: `Enum.Parse` and runtime reflection discovery on the content path. (ADR-0010 Alt 1, Implementation Guidelines)
- Forbidden: a static field that is not `const`, or not `static readonly` of an immutable type (primitive, `string`, or `[ImmutableTable]`). (ADR-0003 §4 no-statics test)

## Acceptance Criteria

*From GDD `design/gdd/content-data-definitions.md`, scoped to this story:*

- [x] For each M-1a content enum (`ItemCategory`, `WeightClass`, `ContainerLayout`, `BeltAccess`, `ContainerView`, `EquipSlot`), the spelling table is bijective: every member has exactly one snake_case data spelling, and every spelling maps back to its member. Lookup works from a UTF-8 `ReadOnlySpan<byte>` with an ordinal byte compare. (CD8)
- [x] Lookups of `"5"`, `"Light"`, `"LIGHT"` and an unknown spelling for `WeightClass` each return not-found. They never fall back to a numeric or case-insensitive parse. Story 018 reports these as CV-GEN-08. (CDD-SCHEMA-4, lookup half)
- [x] A snapshot test of every member's name, numeric value and data spelling fails when a value changes, a value is reused, or a member lacks a spelling. (CDD-SCHEMA-4)
- [x] `System.Enum.Parse`, `Enum.TryParse` and `Enum.GetNames`/`GetValues` are listed in `BannedSymbols.txt` for the Sim. A seeded-use fixture fails the build with RS0030. (CDD-PARSE-4, enum clause)

## Implementation Notes

*Derived from ADR-0010 §2 / Implementation Guidelines and GDD CD8 / CD10:*

- **Location:** `src/PerformativeMail.Sim/Content/Enums/`. Each domain GDD owns its enum's members; this story hosts them (CD8).
- **M-1a members** (CD8 table and CD10; data spelling in brackets):
  - `ItemCategory`: tool, material, consumable, ammo, blueprint, weapon, and `mail` (used for containers).
  - `WeightClass`: light, medium, heavy, bulk.
  - `ContainerLayout`: grid, slots, pile.
  - `BeltAccess`: none, any_side, loading_face, outfeed_only, inserter_only.
  - `ContainerView`: grid, manifest, auto.
  - `EquipSlot`: none, back.
  - `Verb` (Player Character) is not needed by any M-1a def. Its first consumer adds it, through the interaction framework, which is blocked on ADR-0014.
- **Numbering** (implementation decision, logged): members are numbered from **1** in the CD8 order, and **0 is never a valid loaded value**. This matches the F6 worked example, where `weightClass` light encodes as `01 00`. It also means a zero-initialised field can never be mistaken for a real member. Defaulted enums (`BeltAccess.None`, `ContainerView.Auto`, `EquipSlot.None`) still have explicit non-zero values. The FieldSpec default (story 018) supplies them; `default(T)` does not.
- **Tables:**
  - The spelling tables are hand-written `static readonly` immutable tables, marked `[ImmutableTable]` per ADR-0003's no-statics rule, or generated by a source generator referenced as an analyzer. No reflection is used.
  - Lookup compares UTF-8 bytes ordinally.
  - The F6 canonical encoding writes the numeric value as a u16, so these values are part of the content hash. That is why changes are frozen by the snapshot test.
- **Banned APIs:** the BannedApiAnalyzers infrastructure (`BannedSymbols.txt`, `RS0030` = error) is created by `production/epics/simulation-core/story-004-determinism-analyzers-sc-arch-2.md`. This story only appends the `Enum` entries and the seeded-failure fixture. Follow that story's fixture pattern; ADR-0001 §8 requires each fixture to be seen failing.
